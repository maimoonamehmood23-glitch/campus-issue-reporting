# Campus Issue Reporting System

A web app for reporting and tracking campus facility problems (computers, projectors, fans, lights, Wi-Fi).

**Status:** Phase 0 (setup) and Phase 1 (database) complete. Full README will be written in the final phase.

## Quick start
1. `npm install`
2. Copy `.env.example` to `.env` and add your Supabase URL and anon key.
3. Run `supabase/schema.sql` in the Supabase SQL Editor.
4. `npm run dev`
